# Fundora

Mobile-first Nigerian investment platform interface built with React, Vite and TypeScript.

## Current scope
- Blue mobile-first fintech UI
- Investor dashboard
- Four configurable investment plans: ₦10,000, ₦25,000, ₦40,000 and ₦55,000
- Plan selection routes to deposit instructions
- Admin dashboard preview
- Direct bank-transfer deposit workflow with manual verification
- No payment gateway integration

> This repository is a software prototype. A live investment business requires appropriate Nigerian regulatory, KYC/AML, custody, disclosure and operational controls before accepting public funds.
